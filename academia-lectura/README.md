# Biblioteca personal de lectura

Plantilla web estática para leer resúmenes temáticos de doce libros, capturar nueve reflexiones y seguir un plan personal de cuatro semanas.

Abrir dist/index.html en un navegador moderno. No requiere instalación, credenciales ni servicios externos.

Las notas se guardan en localStorage del navegador. Exportar e importar respaldo permite trasladarlas entre dispositivos. No incluye sincronización ni cuentas de equipo.

La plantilla pública contiene un único perfil genérico y ejemplos sobre libros publicados. No contiene nombres, asignaciones internas ni cuadernos privados.

Las portadas son composiciones tipográficas originales. Los resúmenes están redactados en palabras propias y enlazan referencias. No incluyen los libros íntegros.

Verificación: node check.mjs
